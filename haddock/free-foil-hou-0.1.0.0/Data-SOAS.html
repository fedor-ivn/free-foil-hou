Match left-hand side (with metavariables) against the rigid right-hand side.

If matching is successful, it produces metavariable substitutions that when applied to LHS make it syntactically equal to RHS. For example, matching M[f x, g] = g (f x) produces substitution M[z₁, z₂] ↦ z₂ z₁

There may be more than one solution for matching, e.g. M[f x, f x] = f x can be solved with two different substitutions: 1. M[z₁, z₂] ↦ z₁ 2. M[z₁, z₂] ↦ z₂

Hence, this function produces a list of possible substitutions.

Inputs must be well-scoped, with complete variable contexts and correct operator annotations. Matching checks the types of the compared terms and the declared arities and types of metavariables. It does not implement an object-language type checker.
